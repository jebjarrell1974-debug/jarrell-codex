# Reference reader

A working reader over a real slice of the database — Genesis 1, John 1 and
Acts 17, fully resolved. Built and tested before the Android client so the
Compose UI is a port of something known-good rather than a guess.

`demo.json` is generated by `scripts/16_demo_export.py` and is not committed;
regenerate it after a database rebuild.

Open `index.html` beside a generated `demo.json` to run it.
